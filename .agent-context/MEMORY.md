  waits for click/Enter, provides restrained parallax and starts door/bell motion.

  for no JavaScript, reduced motion, forced colours, fragments, short screens and
  background tabs.
- Never call `AudioContext.resume()` or replay blocked bell audio. Sound is local,
  bounded and attempted only from entry.
- Correct top binding uses dark wire loops through rectangular punched slots, not
  floating ovals, dots or lollipop shapes.
- Cookbook paper matches the cream canvas; ruled lines must be absent behind text.
- Browser reviews must run sequentially against the local preview.
- The later category request replaces the single twelve-cake page with six
  top-spiral notebooks under Cakes we've made. Membership/cover choices live in
  `content\notebooks.json`, and every reviewed cake belongs to exactly one book.
